# The owner's test sheet

The test that matters is the owner's own handwriting, written the way it is on a real note.

## How to write it

1. On the tablet: My books > New > New canvas note, named `Erkennungstest`, on the paper you usually use.
2. Write the formulas below with the pen, **in this order, one per line**, the way you normally write. Leave out the
   numbers, and leave about one empty line between formulas.
3. Correct mistakes as usual (erase or scribble out). Only the finished ink counts.
4. Optional, and useful for the phone: the same in a second note, `Erkennungstest Finger`, written with a finger.
5. Open the Windows app and let it sync. Notes sync among devices, and the sheet is read from there.
